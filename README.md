# 晴天 · 一根红线

《周杰伦 - 晴天 [cut_31sec]》的竖屏手绘动态短片（1080×1920，30 fps，31.4 s）。

**构思**：风是一根红蜡笔线。开场它在速写纸上飞行，一笔不断地画出“你”；风最大的时候，它又从发梢开始把“你”拆回成一根线，“我”手里只剩线头；最后线的尽头绕成一个圆，金色水彩在圈里晕开——等到放晴的那天。全片是同一张纸上的一个连续镜头，字幕整句作为演员在场，每段换一次版式，让当下的词最大。分镜和转场见 [TREATMENT.md](TREATMENT.md)。

## 重新渲染

需要 Node 18+、FFmpeg（带 libx264 和 aac）以及本机 Google Chrome（其他路径用 `CHROME_PATH` 指定）。把 `original.mp3` 放在仓库根目录。

```bash
npm ci
npm run render            # → op55-hd.mp4（约 2 分钟）
```

检查用的命令（输出到已被 git 忽略的 `out/`）：

```bash
node scripts/render.mjs --strip 6.6,18.0 --every 2   # 每个时间点连续 10 帧拼成帧条
node scripts/render.mjs --overview                   # 每 0.5 s 一帧的全片联系表
node scripts/render.mjs --frames 0,540,941           # 单帧 PNG
npm run analyze                                      # 原音节拍、强起音、人声能量
```

## 怎么做的

- `src/scene.js`：全部画面。时间轴不实时播放，`SCENE.render(frame)` 只由帧号决定每一帧，所以每次渲染结果都一样。
  - 手绘线：路径按等距重采样，按笔顺逐段画出，粗细随压力噪声和首尾收笔变化；每 2 帧重新抖动一次（line boil）。人物姿态按一拍二更新，镜头逐帧平滑。
  - “你”是一条 680 点的连续折线（手→手臂→裙子→双腿→头→头发）。风暴时一个“拆线前沿”从发梢退到手：前沿之后的点沿着被风弯曲的线排开，线就从她身上一点点放出来。
  - 纸张（斑驳、纤维、颗粒）是程序生成的。纸纹贴图跟着镜头走，用 `destination-out` 咬掉蜡笔、铅笔和文字的一部分，做出纸面颗粒；水彩是多层带噪声的半透明形状，正片叠底。
  - 运动模糊：快的段落每帧渲染 2–5 个子帧（180° 快门）累积；文字每帧只画一次，避免重影。
- `scripts/render.mjs`：本地静态服务器 + puppeteer-core 驱动 Chrome，逐帧取 PNG 管道送进 FFmpeg，同时混入原音（从 0 秒开始，原速，AAC）。
- `scripts/analyze-audio.mjs`：测出 68.5 BPM（拍长 0.8755 s），小节线在 0.50 / 4.00 / 7.50 / 11.01 / 14.51 / 18.01 / 21.51 / 25.01 / 28.52 s，强起音在 9.25 / 12.28 / 16.25 / 19.68 / 23.26 / 28.51 s。转场、牵手、风暴爆发、头被扯走、最后的手化成线、线绕成太阳，都对在这些时刻上。

## 字幕

SRT 只有一条（6.98–7.18 s），整句 23 个字。6.98 s 起一阵风把字逐个吹上纸面，每 6.5 ms 一个，7.16 s 前全部落定，然后整句一直留在画面上到片尾，保证有足够时间读完。原文一字不改。
